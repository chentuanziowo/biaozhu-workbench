    ☁️ 云端同步（Supabase）

    把数据存到云端，手机和电脑自动同步、不再丢数据。数据只存在你自己的 Supabase 项目里。
    三个按钮怎么用？
    • ⬆ 上传本地：你有了新数据（比如刚标注了几条），点这个把本地全部推上云端。它不会读取 / 覆盖你本地任何数据，新记的条目一定在云端了。
    • ⬇ 拉取云端：把云端数据合并回本地（云端有、本地没有的会加进来；本地自己记的、云端没有的会原样保留，不会丢）。
    • 🔄 一键同步：先拉后推，两台设备对齐时用。
    • 🗑 重置云端：当云端数据被污染（比如翻倍）时用——它会先本地去重，然后清空云端全部数据，再用本地干净数据重新上传。⚠️ 此操作会删除云端所有记录，请确认本地数据是正确的再点。
    换设备流程：在有数据的那台点「⬆ 上传本地」→ 另一台点「⬇ 拉取云端」即可。
    首次使用：① supabase.com 建免费项目；② SQL Editor 粘贴建表语句运行；③ 填 URL + anon key → 点「保存并连接」（会做一次初始同步）；两台设备务必填完全相同的 URL / key。
